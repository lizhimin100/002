# Archive — 上下文归档

每写完一章后，执行归档以保持上下文档案最新。

## 工作流

### 第一步：加载素材

1. 读取 `5-上下文/上下文记忆档案.md`（现有档案）
2. 读取 `0-提示词/5-上下文-归档模板.md`（归档模板）
3. 确认用户提供的章节号（如"第5章"）和正文内容

### 第二步：逐项更新（仅动态区）

按模板更新**第二部分：续写指令**。每项更新前**先读现有值**，再根据正文更新：

| 更新项 | 说明 | 数据来源 |
|--------|------|---------|
| 核心事件回顾 | 本章最关键的一个动作/结果 | 本章正文主线 |
| 结尾定格 | 本章最后一句的画面/情绪 | 本章结尾段 |
| 当前危机/目标 | 主角眼下面临的最大难题 | 本章结束后的状态 |
| 时间刻度 | 当前天数/时刻，距关键事件剩余时间 | 正文推算 |
| 主角状态 | 身体伤势/心理状态/关键属性变动 | 正文中状态变化 |
| 持有物品 | 关键道具清单（增/删/用） | 正文中物品变动 |
| 已开辟阶层 | 是否新增 | 正文 |
| 领地/基地 | 核心设施面板/特殊状态 | 正文 |
| 环境/位置 | 具体地点/威胁距离/环境细节 | 结尾定格推算 |
| 伏笔清单 | 新增伏笔追加到清单 | 本章引入的新伏笔 |
| 钩子状态 | 是否有兑现/新埋的钩子 | 正文 |
| 衔接信息 | 结尾情境总结 + 衔接重点 | 本章结尾 |

### 第三步：标注设定变更（若发生）

检查静态区（第一部分）是否需要更新：

- [ ] 是否有新角色长期登场？（追加到人物档案库）
- [ ] 是否有已有角色的人设发生变化？
- [ ] 是否有设定/世界观信息被刷新或补充？
- [ ] 是否有新创造物？（追加到创造物表）

如有变更，标注变更位置，更新后**用 `→` 箭头注明旧值→新值**。

### 第四步：输出确认

生成完整的**第二部分更新内容**，输出给用户确认。用户确认后：

1. 写入 `5-上下文/上下文记忆档案.md`（替换第二部分）
2. 如有设定变更，写入第一部分对应位置
3. **不移除旧内容**，只追加和修正

## 规则

- 永远基于**正文实际内容**更新，不编造、不脑补
- 伏笔清单**只增不删**（已回收的标注"已回收于第X章"）
- 时间线有跳跃时，在时间刻度栏**显式标注跳跃原因**
- 角色状态数值变化须有正文依据，无法确定的标注 `[待确认]`
- 更新完成后不添加分析评价

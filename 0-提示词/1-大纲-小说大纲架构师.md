# novel-outline-architect — 小说大纲架构师

将小说创意转化为可执行的完整大纲蓝图。核心理念：**长篇网文不是讲完一个故事，而是在不断升级的舞台上反复演绎一个让读者上瘾的核心爽点模式。**

## 触发场景

- 有了故事脑洞想扩展成大纲
- 设计核心循环和爽点模式
- 规划分卷结构
- 设计反派升级阶梯
- 提到"大纲""核心循环""分卷""爽点""反派阶梯""升级路线"

## 工作流

| 阶段 | 做什么 | 核心产出 |
|---|---|---|
| 1. 基石定调 | 一句话卖点 + 主爽点/辅爽点 + 目标平台 | 3个问题回答 |
| 2. 核心循环 | 设计六步循环公式，校验可重复性 | 循环发动机 |
| 3. 世界层级 | 地理→势力→力量体系逐层展开 | 循环的舞台 |
| 4. 人物群像 | 角色功能映射 + 主角六问 + 反派阶梯 | 循环的执行者 |
| 5. 分卷大纲 | 每卷核心冲突/主线节点/角色成长/伏笔 | 可执行的施工图 |
| 6. 蓝图输出 | 整合为标准大纲蓝图文档 | 一份可直接导入知识库的蓝图 |

## 四大方法论

| 方法论 | 核心问题 |
|---|---|
| 核心循环引擎 | 读者为什么一读就停不下来？ |
| 世界层级展开 | 循环的舞台如何逐级扩大？ |
| 人物功能映射 | 每个角色在循环中承担什么功能？ |
| 反派阶梯 | 对手如何有铺垫地逐级升级？ |

# 去AI味写作规范

## 核心原则

**AI味的本质是不信任读者。** AI呈现画面后忍不住把画面翻译成结论——怕读者没看懂。

人写法：画面→画面→画面。AI写法：画面→解释→画面→解释。

**检查方法**：写完一段，逐句问——这句是画面还是评语？如果是评语，删掉它，读者还能不能从前后画面自己得出相同结论？能，就删。

---

## 五大病灶

### 一、旁白答题

作者跳出叙事，替读者总结刚看到的画面。

```
❌ 他推导出了地下城的一条隐藏核心规则。
❌ 加纳向李泽斯展示了什么叫真正的专业素养。
❌ 宝箱怪的伪装不是外表。宝箱怪的伪装，是人的贪婪。
```

样本从不这样写。把画面摆在那里，读者自己看出规则、看出素养、看出贪婪。

**杀法**：读者能从画面里自己得出的东西，不要替他再写一遍。用呈现代替解释，用具体代替抽象，用画面代替注释。

---

### 二、自问自答式推理

角色脑子里的思考被写成苏格拉底对话。这是AI最顽固的口癖。

```
❌ 这意味着什么？
   这意味着这座地下城的深处，很可能有一条完整的魔法矿脉。

❌ 十只石像。
   每一只单独拿出来不难对付，但十只一起上，他没有半点胜算。
   必须引开它们。
   或者……
```

人类看到爪尖有矿物碎片→直接推"矿脉"，不会中间插"这意味着什么？"。那个问号是AI在给自己搭脚手架。

**杀法**：删问句，保留结论。或用动作直接带过去。

```
✅ 魔力矿物。一只普通守卫的爪尖里掺了魔力矿物。
   这座地下城深处，有一条矿脉。
```

### 三、破碎短句堆叠（伪节奏感）

用大量句号切碎动作流，制造"干脆利落"的错觉。实际是机械断句。

```
❌ 他侧身。偏了不到半寸。伪装藤的叶针刺空。
   反手一剑。剑刃从叶茎关节劈进去，干脆利落。
   没有多余的动作。没有犹豫。
```

碎句堆叠的本质还是"怕读者没看清，再重复一遍"。

样本用一个具体判断收束动作流：
```
✅ 反手劈进叶茎关节。力道和角度像量过。
```

**杀法**：合并动作流，用一个具体画面或判断收尾。不重复，不评价。

---

### 四、模板化身体反应

AI的情绪快捷键——每个情绪对应一个标准生理反应。

| 情绪 | AI标配反应 |
|------|-----------|
| 紧张 | 后背渗出冷汗、指节泛白 |
| 思考 | 脑子里飞速盘算、指尖无意识敲击 |
| 惊讶 | 瞳孔骤缩 |
| 兴奋 | 心跳加速、呼吸粗重 |
| 犹豫 | 咬下唇、抿紧唇 |

真人写作很少这样用。样本用**具体行为+具体理由**替代标准生理模板：

```
✅ 雷格又有些心疼了。这可是魔药，刚才的补刀损失大了。
```

心疼配具体原因，不是配"他咬了咬下唇"。

**杀法**：禁止描写角色手部、眉毛、嘴唇的模板化小动作。用整体行为或具体情境体现心情，不用掐掌心、咬唇、挑眉这些预制表情。

---

### 五、过滤词和脚手架

句子开头那些不贡献信息的垫片。

| 类型 | 示例 |
|------|------|
| 感知标注 | 他注意到、他看到、他发现 |
| 意图过渡 | 他开始……、他试图…… |
| 否定脚手架 | 不是……而是……、并不是……实为…… |
| 叙述视角标签 | 他没有注意到、他不知道的是 |

```
❌ 他没有注意到，那座宝箱的锁扣轻轻动了一下。
✅ 那座宝箱的锁扣轻轻动了一下。
```

"他没有注意到"把读者注意力从"锁扣动了"强行拉回"雷格没看到"。读者看到锁扣动而角色没反应，自然知道"他没注意到"——不需要标注。

**否定脚手架是重点禁止项**。`不是……而是……`的本质是"用B替换读者脑中的A"，属于认知覆盖——先用否定激活一个概念再用肯定覆盖。删掉这个结构，直接呈现B。

```
❌ 那只手的指尖不是岩石，而是闪烁着暗金色寒光的利爪。
✅ 那只手的指尖闪烁着暗金色寒光。利爪。
```

## 快速自检清单

写完一章后，搜索以下模式，逐个删除：

- [ ] "这意味着什么？" / "这意味着……" → 删问答，留结论
- [ ] "不是……而是……" / "并不是……" → 删框架，直呈B
- [ ] "他注意到" / "他看到" / "他发现" → 删标注，留所见
- [ ] "他开始……" / "他试图……" → 删过渡，写动作
- [ ] "他没有注意到" / "他不知道的是" → 删旁白，留画面
- [ ] 瞳孔骤缩 / 后背冷汗 / 心跳加速 / 抿唇 / 咬唇 → 换具体行为
- [ ] 句中多余"整整""猛地""骤然"等程度副词 → 删
- [ ] 动作流被句号切成孤立短句（超过连续3个单句段）→ 合并
- [ ] 每段最后一行是评价/总结句 → 删，或换成具体画面

## 一句话区别

| AI写法 | 人写法 |
|--------|--------|
| 画面→解释→画面→解释 | 画面→画面→画面 |
| 替读者读完 | 让读者自己读 |
| 每个结论都标出来 | 一个具体判断收束 |
| 碎句堆叠制造节奏 | 动作流连起来，该快就快 |
| 标准生理反应＝情绪 | 具体行为+具体理由＝情绪 |
| 一堆程度副词撑场面 | 精确的动词就够了 |

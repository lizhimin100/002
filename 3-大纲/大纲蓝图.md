# 大纲蓝图 — 地下城之主

## 阶段1：基石定调

- **书名**：地下城之主（暂定）
- **一句话卖点**：骨灰级玩家穿越成新生地下城之主，绑定核心、跑刀掠夺、创造怪物，在地下深处建造前所未有的人控地下城。当攻略者杀穿层层防线抵达最深处——预想中的核心不存在，王座上坐着一个人类。
- **主爽点**：跑刀收获 → 建设进化 → 信息差碾压
- **辅爽点**：陷阱地形杀 + 复活张力 + 创造生命 + 迪化误读 + 期待感排布
- **目标平台**：番茄
- **字数目标**：500-600万字
- **风格基调**：轻松游戏感，主角内心吐槽，使用玩家视角术语（详见上下文记忆档案术语分级），跑刀仅限前期亲自搜刮场景

---

## 阶段2：核心循环·六步公式

```
1. 侦察 → 全图感知扫描周边资源点/探测来犯势力
2. 布局 → 制定跑刀路线+撤退方案/设计分层防御+陷阱链
3. 出击 → 轻装出门跑刀/释放诱饵引敌深入
4. 变数 → 遭遇野怪/巡逻队/意外/敌人比预期强
5. 收割 → 资源到手/战利品+尸体→源质
6. 建设 → 消耗源质升级/创新层/创新生命→衍生新一轮侦察
```

**可重复性校验**：
- 小循环（1-3章）：六步压缩，单章只推1-2步
- 中循环（3-10章）：六步展开为完整故事弧
- 大循环（卷级）：六步映射为卷级节奏

## 阶段3：世界层级

### 3.1 力量体系

**核心资源**：源质（原称地脉之力）
- 来源：核心每日自动吸收 + 超凡装备吸取 + 尸体/血肉转化
- 用途：创新层级、创造生命、凝聚超凡装备、复活

**主角成长线**（非战力，而是地下城能力树）：
- 核心能力：全图感知（地下城内，可看细节，精度随等级提升）→ 开辟新阶层→ 改造阶层结构 → 创造更高级生命
- 成长方式：阶层越多，地下城越强，主角的源质/力量越强
- 限制：主角个人战力天花板有限——永远不正面战斗。优势是情报+布局+主场

**复苏机制**：
- 代价 = 等级 × 生命位阶² 的源质
- 范围：地下城周边20公里
- 源质不足则真死
- 死亡→在核心室复活

**地下城阶层规模**：
| 阶层数 | 形态 | 说明 |
|--------|------|------|
| 1-5层 | 微型 | 自然：基础洞穴，无特产。主角凭金色天赋即可创造特有魔物，跑刀积累期 |
| 6-29层 | 小型 | 自然：开始出现特有魔物雏形，已具初步价值。主角：多层多地形+量产兵种+大阶层BOSS |
| 30-80层 | 中型 | 自然：可孕育特有魔物，BOSS掉落环印石(六阶必需)，支撑贵族家族。主角：自给生态+精锐兵种 |
| 80-120层 | 大型 | 自然：独立生态+多附属空间，足以支撑王国。主角：守护者体系成型+多附属种族 |
| 120层+ | 超大型 | 自然：传说级（如精灵族"世界树之根"）。主角目标：无人能攻略至最深层 |

**外界职业者等级**：
- 学徒(lv1-10) → 黑铁(lv11-20) → 青铜(lv21-30) → 白银(lv31-40) → 黄金(lv41-50) → 圣域(lv51-60) → 传奇(lv61-无上限)
- 超凡位阶：一阶/学徒阶 → 二阶/黑铁 → 三阶/青铜 → 四阶/白银 → 五阶/黄金 → 六阶/圣域 → 七阶/传奇

### 3.2 地理与形态

**地下城外观**：
- 现世后：地面浮现半圆球形石质建筑（直径上百米），石柱+石质门扉，风格各异
- 不同地下城外观各异——本作的风格待定

**地下城内部**（混沌空间中开辟，逐层向下延伸）：
- 核心室：银白色核心漂浮于石质台座上，心脏+复活点+生命绑定所在
- 各阶层：每层有独立地形主题（洞穴层/矿脉层/森林层/沙漠层/沼泽层……），随机或由特定力量创造
- 开辟新阶层需消耗源质，所需源质随层数递增
- 阶层开辟后，入侵者进入则结构锁定，不可再调整
- 每5层一个大阶层，大阶层末尾设BOSS房间

**地下城周边**（跑刀区，20公里复活圈）：
- 森林/山地/废弃矿场/魔兽巢穴/暗河出口
- 散落资源点、野生魔兽、地精部落

**地表世界**（第二卷起展开）：
- 最近人类城镇（冒险者公会所在地）
- 周边领主领地 → 王国/教会势力

### 3.3 势力

| 出场时机 | 势力 | 定位 |
|----------|------|------|
| 第一卷 | 魔兽/地精部落 | 跑刀对手 |
| 第一卷（现世时） | 沃雷家族分支（贵族） | **第一卷大反派** |
| 第一卷中后期 | 白银阶散人强者 | 滞留地下城内成为持续性压力源，迫使主角加速建设 |
| 第二卷 | 冒险者公会 | 攻略→评估→恐惧 |
| 第三卷+ | 王国/教会/其他地下城 | 更大格局 |

## 阶段4：人物群像

### 4.1 主角

- **姓名**：李泽斯（暂定）
- **前世**：骨灰级玩家，RTS/肉鸽/塔防/生存类通吃
- **性格**：理性、善于规划、遇事不慌、习惯性吐槽
- **思维模式**：把一切当游戏——跑刀=低装等进高难图、建地下城=塔防布阵、创造怪物=兵种搭配
- **口头风格**：跑刀用语——"野人来了""这把黑屋局""开智了""加纳"（死了）
- **他要什么**：活下去→不被推平→建成无人能攻略的地下城→改变世界对地下城的认知
- **他怎么变**：躲起来的幸存者→跑刀猎手→地下城建造者→世界格局变量

### 4.2 核心配角（创造的地下城生命）

> 主角不像传统种田文"收编手下"——他用源质+材料创造生命。被创造的怪物视主角为造物主，智商从本能→逐渐成长。

| 创造物 | 类型 | 首次创造 | 定位 |
|--------|------|---------|------|
| 曼德拉草 | 伪装植物 | 第1-3章 | 第一个创造物，阴人专用 |
| 宝箱怪 | 伪装猎手 | 前期 | 高爆发伏击 |
| 石像怪 | 巡逻兵种 | 前期 | 基础量产兵 |
| 水源怪 | 环境陷阱 | 中期 | 水域伏击 |
| 木兵怪 | 战斗兵种 | 中期 | 学习冒险者战斗方式 |
| 分裂藤蔓 | 繁殖母体 | 中期 | 让怪物自繁殖 |
| 木甲怪 | 寄生装备 | 中期 | 寄生于木兵怪，提供武器盔甲 |
| 独眼草 | 侦察单位 | 中期 | 看穿敌人面板 |
| 层级BOSS | 守关者 | 每5层1只 | 层级守护者，实力远超普通怪物 |

### 4.3 反派阶梯

```
第一卷前期：野生魔兽 / 地精部落（"怪物"级，无社会组织）
  ↓
第一卷中后期：黑铁阶冒险者（首批发现者）→ 白银阶散人（第一个真正威胁核心的强者）
  ↓
第一卷反派：沃雷家族分支（贵族，从现世即登场，贯穿全卷）
  ↓
第二卷：冒险者公会讨伐队（"组织"级，有情报有配合）
  ↓
第三卷+：领主骑士团 → 教会审判官 → 王国军（"体制"级）
  ↓
后期：其他地下城主 / 远古存在（"规则"级）
```

## 阶段5：分卷大纲

### 第一卷：地下城，启动！（约80-100章）

**核心冲突**：源质归零的倒计时中跑刀积累+创造生命，在现世前建成基础防御；现世后被沃雷家族分支盯上，必须在地下城被推平前变强到不可撼动。

**时间线**：
- 第1-30章：跑刀积累期（现世前）
- 第40-60章：地下城现世（自动触发）
- 第60-100章：现世后防御战+与沃雷家族博弈

**主线节点**：

**第一幕：醒来与第一次跑刀（第1-3章）**
1. 穿越醒来→发现自己是地下城核心→面板信息→现世倒计时→"我草，这什么鬼地方"
2. 理解绑定和复活机制→发现曼德拉草种子（唯一初始资产）→创造第一个怪物→"小曼，这把黑屋局就靠你了"
3. 第一次出门跑刀（空手）→遭遇第一只魔兽→险死还生/可能死一次→第一份资源→"加纳！不对，老子还活着"

**第二幕：跑刀日常（第4-20章）**
4. 反复跑刀，熟悉周边20公里地图→"这图我背板了"
5. 死亡2-3次，每次复活看到源质槽猛掉→"死不起死不起"
6. 积累第一批源质→建造第二、三层→设计迷宫/假通道
7. 创造宝箱怪、石像怪→"宝箱+石像组合，谁用谁知道"
8. 发现第一处资源点（废弃矿场/魔晶碎片）→"出货了"
9. 遭遇地精部落→跑刀顺便刷地精→地精爆铜币→"野人送快递"

**第三幕：现世前夜（第21-40章）**
10. 现世倒计时逼近→加速建设→第四层（森林层级）+层级BOSS
11. 创造更高级怪物（木兵怪、水源怪）
12. 解锁怪物繁殖能力（分裂藤蔓）→怪物自给自足→"终于不用我一个个手捏了"
13. 发现矿脉/魔树等固定资源→布局在层级中作为"奖励"吸引冒险者
14. 用源质凝聚第一件超凡装备→出门跑刀更安全
15. 全图感知看到远处人迹→"野人要来了"

**第四幕：现世！（第40-50章）**
16. 地下城自动现世→半圆石质建筑破土而出→周边震动
17. 沃雷家族分支（附近领主）第一时间发现→派人探查→**第一卷大反派登场**
18. 第一批冒险者（黑铁阶散人）进入→初级陷阱+曼德拉草收割→"这野人不看技能描述啊"
19. 尸体→源质，装备→吸收→核心每日收益翻倍→"原来被攻略也是资源"
20. 冒险者之间也开始内讧→争夺宝箱→宝箱怪趁机双杀→"野人互殴，爱看"

**第五幕：第一个真正的威胁（第51-70章）**
21. 攻略者越来越多，沃雷家族开始垄断入口收费
22. 沃雷家族派专业攻略队深入→推进到第三层→"这队有点东西"
23. 攻略队抵达第四层→遭遇层级BOSS→被击退但BOSS也暴露了弱点→"完了，被摸透了"
24. 白银阶散人强者登场→单人深入→连破两层层级→直逼核心→"我草，野人开智了！"
25. 主角的层级BOSS+陷阱+亲自指挥→与白银阶的惨烈攻防→白银阶被击退但核心差一点被攻破→"差点黑屋局"
26. 劫后余生→加速建设第五、六层→用白银阶的战斗数据迭代怪物→"感谢大佬送的数据"

**第六幕：与沃雷家族的正面对抗（第71-100章）**
27. 沃雷家族精英队（超凡阶带队）→正式攻略→推进到第五层
28. 主角设计"永囚之井"层级BOSS+多重陷阱链→沃雷精英队被层层消耗
29. 沃雷家族惨败→但主角知道这只是分支，主家会来→"打了小的来老的"
30. 大量超凡阶尸体→源质暴增→一口气开两层
31. 第七层发现宝物（如替生木）→"出货了！传说品质！"
32. 卷末：地下城被冒险者公会正式评级→沃雷家族主家收到消息→更大规模的势力开始关注→"下个版本更难了"
33. 收尾钩子：主角看向刚开的第八层→地底深处传来不明震动→"还有更深的？"

**第一卷角色成长**：恐慌的幸存者→跑刀老手→地下城建造者→初战告捷的城主
**伏笔埋设**：沃雷家族主家、冒险者公会、地下更深的震动、白银阶强者长期滞留

## 1. 核心设定锚定

### 世界观底层

- 西幻世界，地下城是超凡力量唯一来源。人类冒险者攻略地下城获取财富与力量。
- 地下城由核心驱动，在混沌空间中开辟阶层，诞生后自动现世（有倒计时）。现世时地面浮现半圆球形石质建筑（直径上百米），石柱+石质门扉。
- 普遍认知：地下城=野生怪物巢穴+财富来源。核心=死物。怪物=没有智慧。在主角之前，从未有人类控制过地下城。
- 主角原身穿越，占据绑定新生地下城核心。核心=主角心脏，核心被摧毁=真死。核心可随阶层开辟转移到更深层。

### 力量/成长体系

**核心资源：源质（原作"地脉之力"）**
- 来源：核心每日自动吸收 + 宝物/钱币/超凡装备放在核心旁吸取 + 入侵者尸体/血肉转化
- 用途：开辟新阶层、创造生命、改造阶层、凝聚超凡装备、支付复活代价
- 吸取效率：铜币 < 银币 < 金币 < 宝矿石 < 超凡装备

| 6-29层 | 小型 | 自然：开始出现特有魔物雏形，已具初步价值。**主角**：多层多地形，量产兵种+魔法陷阱，大阶层末尾设BOSS |

**外界职业者等级**
- 学徒(lv1-10) → 黑铁(lv11-20) → 青铜(lv21-30) → 白银(lv31-40) → 黄金(lv41-50) → 圣域(lv51-60) → 传奇(lv61-无上限)
- lv11突破超凡=第一次质变，需要机缘/濒死刺激

**超凡位阶**：一阶/黑铁(lv11-20) → 二阶/青铜(lv21-30) → 三阶/白银(lv31-40) → 四阶/黄金(lv41-50) → 五阶/圣域(lv51-60) → 六阶/传奇(lv61+)

**装备等级**：凡品 → 含魔材料 → 小魔力级 → 大魔力级 → 杰作级 → 宝藏级 → 神遗物级 → 神器

**常见职业**：剑士(魔力强化肉体)、魔法师(魔力储存释放)、骑士(骑乘+指挥)、重战士(重甲攻坚)。特殊职业由天赋/血脉决定。

### 主角人设内核

- **姓名**：李泽斯
- **前世**：骨灰级玩家（RTS/肉鸽/塔防/生存类通吃），原身穿越，占据绑定地下城核心
- **性格**：理性、善于规划、遇事不慌、习惯性吐槽。把一切当游戏理解。
- **口头风格**：三角洲主播式吐槽——"野人来了""这把黑屋局""开智了""加纳"
- **内在驱动**：活下去 → 不被推平 → 建成无人能攻略的地下城 → 改变世界对地下城的认知
- **道德立场**：实用主义。入侵者=养料来源。不分善恶，闯进来的都得死。不刻意残暴，只为活下去。
- **战力定位**：个人战力天花板有限，永远不正面战斗。优势是情报+布局+主场。

**金手指：地下城核心绑定**

| 能力 | 说明 |
|------|------|
| 核心复活 | 死亡可在核心室复活。代价=等级×生命位阶²的源质，不足则真死。范围=地下城周边20公里内 |
| 全图感知 | 地下城内部全图感知（可看细节，精度随等级提升） |
| 开辟阶层 | 消耗源质，在混沌空间中开辟新阶层；阶层越多地下城越强 |
| 改造阶层 | 调整已有阶层结构（入侵者进入后不可改，只能转移怪物） |
| 创造生命 | 消耗源质+材料，创造物视主角为造物主。天赋：魔物创造[金色] |
| 血肉吸取 | 紫色天赋，吸收消化地下城内所有血肉→源质 |
| 凝聚装备 | 用源质凝聚超凡装备（出门跑刀用；自产装备无法被核心吸取） |
| 每日吸收 | 核心每日自动从大地吸收源质 |

### 模板系统

> 创造魔物 = **种族（肉体/天赋技能） + 模板（特性包）**。两者互斥，一怪一模板。
> 其他新生地下城本能地做「尖牙」「利爪」「厚皮」之类动物性模板；主角凭游戏阅历做出「脱战恢复+气息隐秘」——低成本高组合效果的build思路。

**等阶体系**

| 等阶 | 名称 | 预算帽 | 定位 |
|------|------|--------|------|
| 一阶 | **爪牙** | 低 | 炮灰杂兵，基础特性模板 |
| 二阶 | **小怪** | 中低 | 量产主力，少量特性 |
| 三阶 | **精英** | 中高 | 精锐战力，多特性/中强特性 |
| 四阶 | **冠位** | 极高 | BOSS级模板，可量产（源质足够） |
| 特殊 | **使徒** | 另算 | 限量槽位（核心等级解锁），有自我意识/管辖区域/赐福印记。需种族基底 |

**模板槽位**（有限，不可删除，只能废弃不用）

| 地下城规模 | 阶层 | 槽位 |
|-----------|------|------|
| 微型 | 1-5层 | 3 |
| 小型 | 6-29层 | 6 |
| 中型 | 30-80层 | 15 |
| 大型 | 80-120层 | 32 |
| 超大型 | 120+ | 无限 |

**创造流程**

```
主角脑中构思/灵感 → 将描述输入面板 → 面板验证可行性 → 给出消耗报价
→ 主角确认加入当前模板 → 全部特性确认完毕 → 固定模板（此时扣源质）
→ 模板挂入模板库 → 创造魔物时：选种族 + 选模板 = 成品
```

**三层限制**：(1)灵感门槛——想得出描述面板才受理；(2)源质消耗——特性越多越强消耗越高；(3)等阶预算帽——总消耗不得超出该等阶上限。

**特性品质**：白（普通）→ 绿（优秀）→ 蓝（稀有）→ 紫（史诗）→ 红（传说）→ 金（神话）→ 彩（原初/唯一级）

**特性进阶与冲突**
- 特性可单独花源质升品质，不触发预算重算（预算仅限创建时），为前期槽位有限不可删除提供升级出口
- 面板自动检测特性冲突（如「气息隐秘」与「威压光环」），提示但允许强行塞入——出问题后果自负
- 模板等阶不可升：爪牙永远是爪牙，做精英必须新做
- 模板不可删除，已创造魔物不受模板废弃影响
- 特性由系统自动命名，模板可自定义名称

**主角独有优势**：游戏阅历 → 设计出野生地下城本能想不到的特性组合；Build思维 → 同一预算帽下组合效果远超动物性模板。例：「脱战恢复」（白）+「气息隐秘」（绿）= 骚扰型游击单位。

## 2. 核心循环·六步公式

> 小说核心发动机。所有章节均围绕此循环展开。

```
1. 侦察 → 全图感知扫描周边资源点/探测来犯势力
2. 布局 → 制定跑刀路线+撤退方案/设计分层防御+陷阱链
3. 出击 → 轻装出门跑刀/释放诱饵引敌深入
4. 变数 → 遭遇野怪/巡逻队/意外/敌人比预期强
5. 收割 → 资源到手/战利品+尸体→源质
6. 建设 → 消耗源质升级/创新层/创新生命→衍生新一轮侦察
```

**嵌套节奏**：
- 小循环（1-3章）：六步压缩，单章只推1-2步
- 中循环（3-10章）：六步展开为完整故事弧
- 大循环（卷级）：六步映射为卷级节奏

**主角成长弧**：躲起来的幸存者 → 跑刀猎手 → 地下城建造者 → 世界格局变量

## 3. 核心爽点体系（八大爽点）

| # | 爽点 | 机制 | 效果 |
|---|------|------|------|
| 1 | 跑刀收获爽 | 空手出门→满包回家，风险收益成正比 | 即时满足 |

| 4 | 陷阱地形杀爽 | 不是主角强，是每一层都是他设计的战术方案 | 策略满足 |

| 7 | 迪化/误读爽 | 外界过度解读地下城→学术理论/教会预言→全错 | 反差笑点 |
| 8 | 期待感排布爽 | 单章2-3个活跃期待点，爽点兑现→衍生新期待 | 翻页动力 |

## 5. 地理与关键地点

### 5.1 地表世界

- **当前区域**：兰西王国西北边境，森林与丘陵交界的平原
- **最近城镇**：铜水城（冒险者公会所在地）
- **邻国**：格里王国（金发=贵族，与兰西相反）
- **周边地形**（地下城20公里复活圈=跑刀区）：森林/山地/废弃矿场/魔兽巢穴/暗河出口/地精部落

### 5.2 地下城外观

- 半圆球形石质建筑，直径上百米
- 石柱+石质门扉，现世后浮现于地面
- 不同地下城外观各异

### 5.3 地下城内部结构

- **核心室**：银白色核心漂浮于石质台座上。心脏+复活点+生命绑定所在。
- **各阶层**：每层独立地形主题（洞穴/矿脉/森林/沼泽/沙漠/熔岩……）。逐层向下延伸。
- **BOSS房间**：每5层一个大阶层，大阶层末尾设BOSS房间（样本书：第5层/第10层/第15层……）
- **结构锁定**：入侵者进入后，当前阶层结构锁定，不可调整（只能转移怪物）。
- **附属阶层**（后期可能）：独立于主楼层的特殊区域，智慧物种聚集地。

### 5.4 地下城外驻扎地

- 现世后自发形成：帐篷 → 木屋 → 小镇雏形
- 功能分区：广场（交易/组队）、商人收购点、旅店餐馆

## 6. 分卷概览

### 第一卷：地下城，启动！（约135章，34万字）

**核心冲突**：三重倒计时——72小时现世冲刺+现世后沃雷家族威胁+白银阶厄德瓦尔滞留→持续性内部压力。跑刀每趟=一个"以小博大"故事单元。

**时间线**：
- 第1-12章：72小时倒计时跑刀冲刺（现世前，7趟跑刀）
- 第13-44章：现世后跑刀+魔物自治收割+沃雷家族介入（~8趟跑刀）
- 第45-80章：厄德瓦尔(白银)登场→滞留→压力→加速开层→沃雷分支出局

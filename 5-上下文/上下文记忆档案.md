# 第一部分：静态设定

## 1. 世界观

- 西幻世界"希尔德隆"。地下城=超凡力量唯一来源。主角肉身穿越，部分灵魂绑定新生地下城核心，核心被摧毁=真死。
- 钱币和宝石类物品放在核心旁可加持核心，提高每日源质产出。普通装备无此效果。
- **地形锁死规则**：有入侵者的楼层无法改变地形（只能转移魔物），无入侵者楼层不受限。
- **迷宫筛选机制**：每层均为迷宫结构（大量假通道+环形死循环+岔路口石壁刻意做成一模一样）。入口不是"找到的"——是被迷宫消磨掉足够多人命后才被标记在地图上的。平面迷宫可被地图标记破解，后续主角升级为立体迷宫应对。

## 2. 魔物体系

- **流程**：消耗源质+提供材料→魔物创造。材料和构思决定魔物基底和技能倾向（植物→伪装/缠绕，矿石→防御/破甲），源质投入量影响强度上限。
- **品质分级**：爪牙/小怪/精英/头目。
- **已有魔物**：伪装藤×3(Lv2)、宝箱怪×3(Lv3)、守护石像×14(Lv2→Lv3部分升级)、水源怪×8(Lv4)
- **新资源**：第3层黑耀金矿脉（魔法矿物，极硬+吸魔，拳头大=王都一套宅子，战略价值=永续吸引养料）

## 3. 标点与风格

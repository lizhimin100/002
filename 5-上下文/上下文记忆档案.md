# 第一部分：静态设定

## 1. 世界观

- 西幻世界"希尔德隆"。地下城=超凡力量唯一来源。主角肉身穿越，部分灵魂绑定地下城核心，核心被摧毁=魂飞魄散真死。肉身死亡后灵魂回归核心重塑躯体。
- 钱币和宝石放核心旁可加持核心，提高每日源质产出。普通装备无效。
- **地形锁死**：有入侵者的楼层无法改变地形，无入侵者楼层不受限（Ch3推导）。
- **阶层结构**：垂直向下延伸，新阶层开辟时核心连同台座下沉。每5层为大阶层，末尾可放置BOSS级魔物（Ch9核心解锁）。BOSS拥有独立战斗智慧+领域压制，击败BOSS才显现下层入口，入口随BOSS复活刷新再次关闭。
- **领主战略**：控制入口→迷宫太深填不起→默许散人进入，关卡不撤但不拦（Ch3→Ch5→Ch6）。

## 2. 魔物体系

- **流程**：实物基底+源质→创造。基底材料决定形态倾向，源质量影响等级。已有魔物可回炉升级。顶级魔力矿物可替代源质消耗仅需极少源质作引子。
- **魔物创造叙事规范**（严格执行，不得偏离）：

  **1. 触发灵感（1-2句）**：两种来源——①外部触发（冒险者的话语/行为让主角眼睛一亮，"连个宝箱都没有"→宝箱怪，"连口水都没有"→水源怪，"又炸锅了不干了"→菌羚）；②内部触发（主角自身战术推演感知到需要，"石像损耗太大"→分裂菇，"需要后勤通讯"→菇网，"白银阶太强需要能拖的刺客"→黑耀守卫）。禁止纯抽象战略说明作为唯一触发。

  **2. 取材（1句）**：从环境中快速提取材料，不解释"为什么用这个材料"。只写动作，不留设计文档痕迹。

  **3. 核心发光+命令（1-2句）**：固定格式——核心亮起紫芒 → `"魔物，创造！"`。此句不可替换为"融合""合成""生成"等任何变体。若同时创造多只、批量创造或创造基础设施（菇网），命令相同。

  **4. 变形描写（2-4句）**：纯视觉画面。材料在空中扭曲、融合、定型。不解释机制，不写"第一步第二步"。声效词可加（"啪"的砸落、"咔咔"拼接），但声效后不用破折号。

  **5. 面板（静态内嵌）**：创造完成后立即弹出，固定格式：
  ```
  [李泽斯的未命名魔物 LvX]
  [技能：A / B / C]
  [描述：一句话。]
  ```
  再展示新魔物的特性、性格，但最核心的一点就是对主角的绝对忠诚。
  **5.5 命名即绑定（1行）**：命名后立即追加一行面板更新，格式：
  ```
  [李泽斯的XX LvX]
  ```
  命名前用`[李泽斯的未命名魔物]`，命名后替换为`[李泽斯的+最终名称]`。批量生产单位无个体名称时直接显示类型名（如`[李泽斯的守护石像Lv8]`、`[李泽斯的狂沙骷髅]`）。

  **6. 魔物性格（1-2句）**：诞生后的小动作——羞怯/邀功/蹭核心/缩进阴影/生根不动。让它"活"起来。不可省略。

  **7. 命名+部署（2-3句）**："以后就叫你阿X了"/"就叫你XX吧" → 面板更新行 → 传送到指定位置。三件事严格按此顺序。
